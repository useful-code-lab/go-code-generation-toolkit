
## Команда `generator-example`
Основная задача команды `generator-example` — подготовить базу для понимания того, как работают инструменты генерации кода, такие как **protoc** (Protocol Buffers). Разбор внутреннего устройства рантайма позволяет эффективно писать кастомные генераторы и оптимизировать производительность генерируемого кода.

### Запуск
```
$ cd ~/gopher-lab/cmd/generator-example
```
```
$ go generate
```
Как результат рядом с ``main.go`` должен появиться файл ``hello_gen.go``
